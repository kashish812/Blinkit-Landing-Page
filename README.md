# Blinkit Landing Page

A responsive static landing page inspired by Blinkit's quick-commerce experience.

## Project structure

```text
.
├── assets/
│   ├── desktop.png
│   └── mobile.png
├── css/
│   └── style.css
├── index.html
├── README.md
└── .gitignore
```

## Run locally

Open `index.html` in a browser. This static site uses HTML and CSS and does not require a backend or build command.

## GitHub Pages

In the repository's Pages settings, choose **Deploy from a branch**, select `main`, and choose `/(root)`. The root `index.html` is the entry point.

The page loads DM Sans from Google Fonts when an internet connection is available and falls back to Arial otherwise.
